# 挂一碗面

店里开「挂一碗」：有人先付钱挂在墙上，有需要的人来了直接领一碗。按开张挂了几碗、每天平均来领几人、挂进几碗、算几天（可选每天最多送几碗），算这段日子一天都不断碗的把握、平均几人次空手回去、开张至少要挂几碗。

- 模型：每天来挂、来领人数各为泊松分布，天与天独立，当天挂的当天能领；按墙上碗数的概率分布逐天精确推算（不是随机模拟），1e-17 以下的尾巴丢弃并记账。
- 「开张至少挂几碗」用二分：碗数越多，每条到达路径上墙上的碗只多不少，所以一天不断的把握随碗数单调不减。
- 测试：`node --test tests/core.test.cjs`；独立参考 `python3 tests/ref.py`（联合状态字典 + lgamma 泊松 + 逐个往上试）生成 `tests/ref.json`；注入测试 `node tests/inject.cjs`。
- 默认店铺和数字都是虚构示例；真实店里的人数通常更忽高忽低，算出的把握偏乐观。
